# Frontend Design Skill

This skill enables creation of distinctive, production-grade web interfaces that prioritize creative excellence over generic aesthetics.

## Key Principles

**Design Direction**: Before coding, establish a bold aesthetic commitment—whether brutalist, maximalist, retro-futuristic, or another intentional direction. The approach emphasizes "understanding context and committing to a BOLD aesthetic direction" rather than defaulting to common patterns.

**Critical Elements**:
- **Typography**: Select characterful, unexpected fonts rather than defaults like Arial or Inter
- **Color**: Use dominant colors with sharp accents via CSS variables
- **Motion**: Employ CSS animations and scroll-triggered effects strategically
- **Composition**: Apply asymmetry, overlap, and grid-breaking layouts
- **Details**: Incorporate textures, gradients, and contextual visual depth

**What to Avoid**: Generic aesthetics including overused font families, clichéd color schemes (purple gradients), and predictable component patterns that lack context-specific character.

## Implementation Approach

Match code complexity to the vision—maximalist designs warrant elaborate animations; minimalist designs require precision in spacing and typography. The emphasis is on executing the chosen direction thoroughly rather than applying intensity uniformly.

The skill leverages HTML/CSS/JavaScript, React, Vue, and similar frameworks to produce "working code with exceptional attention to aesthetic details and creative choices."
